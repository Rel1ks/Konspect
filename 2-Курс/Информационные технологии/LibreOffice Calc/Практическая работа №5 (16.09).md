#### Создание и редактирование таблиц

Таблица в LibreOffice Calc состоит из строк и столбцов, а их пересечение образует ячейку. В ячейки вводят текст, числа и другие данные. При редактировании таблицы меняют содержимое ячеек, добавляют или удаляют строки и столбцы, а также изменяют ширину столбцов и высоту строк.
#### Сортировка таблиц

Для сортировки данных используется команда Данные - Cортировка. Перед сортировкой нужно выделить нужный диапазон таблицы. Данные можно расположить по возрастанию или убыванию. Текст сортируется по алфавиту, а числа — от меньшего значения к большему или наоборот.
#### Вычисления в таблицах

В LibreOffice Calc вычисления выполняются с помощью формул. Формула начинается со знака =. Например, формулы:

- =A1+B1 (сложение)
- =SUM(A1:A5) (сумма нескольких ячеек)
- =AVERAGE(A1:A5) (среднее значение)

После ввода формулы нажимается клавиша Enter, после чего в ячейке появляется результат.
#### Преобразование текста в таблицу

Текст можно преобразовать в таблицу командой Таблица - Преобразовать - Текст в таблицу. Сначала выделяется нужный текст, затем выбирается указанная команда. В появившемся окне указывается разделитель, например табуляция. После подтверждения текст распределяется по строкам и столбцам.
#### Открытие приложения табличного процессора и структура экрана

Для работы с электронными таблицами открывается приложение LibreOffice Calc. После запуска появляется окно с рабочей областью для создания и редактирования таблиц. Окно LibreOffice Calc включает строку заголовка, меню, панели инструментов, строку формул, рабочую область, полосы прокрутки и строку состояния. Рабочая область состоит из строк и столбцов. Строки обозначаются числами, а столбцы — буквами. Пересечение строки и столбца образует ячейку.
#### Меню и панели инструментов

Меню расположено в верхней части окна и содержит основные команды для работы с документом. С его помощью можно создавать, открывать и сохранять документы, изменять таблицы, выполнять сортировку и использовать другие функции программы.

Панели инструментов содержат кнопки для быстрого выполнения различных действий. С их помощью можно создавать, сохранять и редактировать документы, изменять формат текста, выравнивать содержимое ячеек, добавлять границы и выполнять другие операции.
#### Создание и сохранение документа

Для создания нового документа выбирается Файл - Создать - Электронная таблица. Для сохранения документа используется команда Файл и Сохранить как. После этого указываются имя файла, место сохранения и формат документа. 
#### Знакомство с элементами окна

Основными элементами окна являются строка заголовка, меню, панели инструментов, строка формул, рабочая область, строки, столбцы, ячейки, полосы прокрутки и строка состояния. Строка заголовка показывает название открытого документа. 
Меню содержит команды для работы с программой. Панели инструментов позволяют быстро выполнять основные действия. Рабочая область предназначена для работы с данными. 
Строки обозначаются числами, столбцы — буквами, а ячейки используются для ввода информации. Строка формул позволяет просматривать и изменять содержимое активной ячейки. Полосы прокрутки используются для перемещения по таблице. Строка состояния находится в нижней части окна и показывает информацию о текущем документе.
