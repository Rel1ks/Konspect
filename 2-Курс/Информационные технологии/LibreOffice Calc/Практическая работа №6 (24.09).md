### Перемещение указателя ячейки

Активная ячейка — ячейка, с которой в данный момент выполняется работа

- Щёлкнуть по ячейке мышью - cделать её активной
- Клавиши со стрелками - перемещение на одну ячейку
- Enter -переход на следующую строку
- Tab - переход на следующую ячейку вправо
- Ctrl + стрелка - переход к краю заполненного диапазона
- Home - переход к началу строки
- Ctrl + Home - переход в ячейку A1
- Ctrl + End - переход к последней используемой ячейке
### Выделение диапазонов

Диапазон это группа ячеек

- Одна ячейка - щёлкнуть по ней
- Смежный диапазон - зажать левую кнопку мыши и протянуть указатель
- Shift + стрелки - расширение выделения от активной ячейки
- Столбец - щёлкнуть по его букве
- Строка - щёлкнуть по её номеру
- Весь лист - кнопка в левом верхнем углу между названиями столбцов и номерами строк
- Несмежные диапазоны - выделить первый диапазон, затем удерживать Ctrl и выделять другие диапазоны
### Ввод и редактирование данных

В ячейку можно вводить текст, числа, даты и формулы.

Выбрать ячейку и начать ввод с клавиатуры.

- Enter - подтвердить ввод
- Esc - отменить текущий ввод
- F2 - редактировать содержимое ячейки
- Двойной щелчок по ячейке - перейти к её редактированию
- Delete - удалить содержимое выбранных ячеек

Для изменения уже введённых данных можно также использовать строку ввода над таблицей
### Установка ширины столбцов

Ширину столбца можно изменить несколькими способами:

- Перетащить границу между буквами столбцов мышью
- Дважды щёлкнуть по границе столбца - автоматически подобрать ширину по содержимому
- Выделить столбец и выбрать Формат - Столбцы - Ширина
- Можно выделить несколько столбцов и установить одинаковую ширину сразу для всех
### Автозаполнение

Автозаполнение позволяет быстро продолжать последовательность или копировать данные

- Ввести значение в ячейку
- Навести указатель на маленький квадрат в правом нижнем углу ячейки - маркер заполнения.
- Зажать левую кнопку мыши и протянуть маркер в нужную сторону.

Примеры:

1, 2 → протягивание продолжит 3, 4, 5…
Понедельник - можно получить следующие дни недели.
Формулу можно протянуть на соседние ячейки - ссылки в ней изменятся автоматически
### Формулы для смежного диапазона

Формула начинается со знака =

Например:

- =A1+B1 — сложение двух ячеек.
- =A1B1 — умножение.
- =SUM(A1:A5) — сумма диапазона.

Чтобы ввести формулу для нескольких смежных ячеек:

- Ввести формулу в первую ячейку
- Нажать Enter
- Использовать маркер заполнения и протянуть формулу на остальные ячейки

Например, если в C1 записано =A1+B1, то при копировании вниз в C2 формула станет =A2+B2
### Формулы для несмежного диапазона

Несмежный диапазон состоит из отдельных ячеек или диапазонов, которые не находятся рядом

Например, можно выбрать A1, C1 и E1 с помощью Ctrl. Для вычислений можно использовать несколько отдельных ячеек:  
- =SUM(A1;C1;E1)

Таким образом, функция SUM может работать как с одним диапазоном, так и с отдельными ячейками
### Копирование формул

Формулу можно копировать с помощью:

Ctrl + C — копировать.
Ctrl + V — вставить.

Маркера заполнения - быстро скопировать формулу в соседние ячейки При обычном копировании относительные ссылки изменяются

Например:

В B1: =A12
При копировании в B2 получится: =A22

Если нужно, чтобы ссылка не изменялась, используется абсолютная ссылка со знаком $:

=$A$12
### Копирование формул в несмежные ячейки

- Ввести формулу в исходную ячейку
- Скопировать её через Ctrl + C
- С помощью Ctrl выделить нужные несмежные ячейки
- Нажать Ctrl + V

Формула будет вставлена во все выбранные ячейки с учётом относительных и абсолютных ссылок
