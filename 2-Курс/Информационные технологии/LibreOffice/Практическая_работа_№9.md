#LibreOffice #информационные_технологии
## Практическая работа №9
### Работа с рисунками в документе
LibreOffice Writer позволяет встраивать в документ растровые и векторные изображения, схемы, фигуры и объекты из других приложений. Все графические объекты после вставки становятся полноценными элементами документа: их можно перемещать, масштабировать, выравнивать относительно текста и страницы, а также объединять в группы для совместного редактирования. Работа с рисунками ведётся через панель инструментов _Рисунок_, боковую панель свойств и контекстное меню, которое появляется при щелчке правой кнопкой мыши по выделенному объекту.
### Вставка рисунков
Вставка готового изображения выполняется через меню **Вставка** $\rightarrow$ **Рисунок**. В открывшемся диалоге выбирается файл с расширением `.png`, `.jpg`, `.bmp`, `.svg` и т.д. После вставки рисунок появляется в тексте как объект с привязкой _К параграфу_ или _К символу_. Альтернативный способ — перетаскивание файла из файлового менеджера прямо в рабочую область документа. Для замены изображения без потери позиции и форматирования удобно пользоваться контекстным пунктом _Заменить рисунок_.
### Составление блок-схемы
Блок-схемы собираются из набора готовых фигур, доступных на панели **Рисунок**. Фигуры вставляются кнопкой _Вставить фигуры_ и далее выбираются из каталога: прямоугольники, ромбы, овалы, стрелки, линии. После вставки каждая фигура выделяется щелчком мыши, а для соединения блоков используется инструмент _Соединительная линия_, который автоматически привязывается к точкам входа/выхода фигур и перестраивается при их перемещении. Текст внутрь блока добавляется двойным щелчком по фигуре.
### Переупорядочивание слоев рисунка и вращение фигур
Когда в одном месте документа находится несколько графических объектов, их видимость и порядок прорисовки управляются через команды контекстного меню **Упорядочить**: _На передний план_, _На задний план_, _Вперёд_, _Назад_. Эти же команды доступны на панели свойств объекта. Вращение фигур выполняется через диалог **Положение и размер** (`F4`), где задаётся точный угол поворота, либо интерактивно — зелёным маркером над выделенным объектом. Для зеркального отражения фигур и изображений используется команда контекстного меню _Отразить_ с вариантами по вертикали или горизонтали.
### Создание рисунка-подложки для текста
Чтобы превратить рисунок в подложку (фон страницы), нужно изменить его привязку на _Как символ_ или _К странице_ через панель свойств и затем отключить обтекание текстом, выбрав режим _Без обтекания_. Дополнительно через **Формат** $\rightarrow$ **Объект** $\rightarrow$ **Положение и размер** задаётся расположение объекта в абсолютных координатах страницы. Альтернативный путь — использование стиля страницы: меню **Формат** $\rightarrow$ **Стиль страницы** $\rightarrow$ вкладка _Фон_ позволяет добавить изображение как фоновый рисунок для всего раздела документа.
### Управление обтеканием рисунка текстом
Режим обтекания выбирается в контекстном меню объекта пунктом **Обтекание текстом**. Доступны варианты: _Без обтекания_, _На параграфе_, _Вокруг_, _Сквозное_, _Вверху_/_Внизу_. Каждый режим настраивается по расстояниям до текста: горизонтальный и вертикальный отступы задаются в окне свойств объекта. Для сложных контуров используется команда _Изменить контур обтекания_, которая позволяет обвести рисунок произвольной линией и добиться точного прилегания текста.
### Работа с научными формулами
Редактор формул LibreOffice Math вызывается через меню **Вставка** $\rightarrow$ **Объект** $\rightarrow$ **Формула**. Открывается отдельное окно с текстовым полем для ввода выражения в специальной нотации и панелью символов. Например, дробь записывается как `a over b`, корень — `sqrt{a}`, интеграл — `int from {a} to {b} f(x) dx`, степень — `a^{2}`. После закрытия редактора формула встраивается в документ как объект и масштабируется вместе с текстом. Для редактирования достаточно дважды щёлкнуть по формуле — снова откроется Math с текущим выражением.
## Глава 2. Табличный процессор (LibreOffice Calc)
### Табличный процессор
LibreOffice Calc — это табличный процессор, предназначенный для хранения, обработки и анализа данных, представленных в виде прямоугольных таблиц. Рабочая книга состоит из листов, между которыми можно переключаться через ярлыки в нижней части окна. Каждая ячейка листа имеет собственный адрес вида `A1`, `B12`, `C7`, который используется в формулах и ссылках. Calc поддерживает широкий набор встроенных функций: математических, статистических, логических, текстовых, финансовых и функций для работы с датами.
### Создание книг, форматирование, специальные возможности
Новая книга создаётся через меню **Файл** $\rightarrow$ **Создать** $\rightarrow$ **Электронную таблицу** или комбинацией `Ctrl + N` с последующим выбором шаблона. Форматирование ячеек выполняется через **Формат** $\rightarrow$ **Ячейки** (`Ctrl + 1`): задаются числовой формат, шрифт, выравнивание, границы и заливка. Для быстрой работы с большими объёмами данных используются: автофильтр (**Данные** $\rightarrow$ **Автофильтр**), условное форматирование (**Формат** $\rightarrow$ **Условное форматирование**), промежуточные итоги (**Данные** $\rightarrow$ **Итоги**) и сводные таблицы (**Данные** $\rightarrow$ **Сводная таблица**). Защита листа и книги включается через **Сервис** $\rightarrow$ **Защитить документ**.
### Формулы VB (макросы)
Для автоматизации повторяющихся действий в Calc используются макросы на языке Basic, синтаксис которого совместим с макросами VBA Microsoft Excel. Запись макроса запускается через **Сервис** $\rightarrow$ **Макросы** $\rightarrow$ **Записать макрос**, после чего все действия пользователя преобразуются в код. Редактирование и написание макросов вручную выполняется во встроенной среде **Basic IDE**, доступной через **Сервис** $\rightarrow$ **Макросы** $\rightarrow$ **Управление макросами**. Типичный макрос обращается к книге через `ThisComponent`, к листу — через `ThisComponent.Sheets.getByName("Лист1")`, а к ячейке — через `Sheet.getCellByPosition(0, 0).setString("Hello")`. Запуск готового макроса выполняется через **Сервис** $\rightarrow$ **Макросы** $\rightarrow$ **Выполнить макрос** или назначением на кнопку панели инструментов / горячую клавишу.
