#### Просмотр документа

#### В LibreOffice Writer доступно несколько режимов просмотра документа:

- Обычный — основной режим работы с документом
- Веб — документ отображается как веб-страница
- Во весь экран — документ занимает весь экран

Кроме того, можно менять масштаб просмотра. Масштаб влияет только на отображение документа на экране.
#### Перемещение по документу

Перемещаться по документу можно мышью, полосой прокрутки и клавиатурой. Навигатор открывается клавишей F5. С его помощью можно переходить по страницам, заголовкам, таблицам, закладкам и другим элементам документа. Основные клавиши:

- Home — начало строки.
- End — конец строки.
- Page Up — вверх на один экран.
- Page Down — вниз на один экран.
- Ctrl + Home — начало документа.
- Ctrl + End — конец документа.

Для перехода к определённой странице используется команда Перейти.
#### Закладки

Закладка — метка в определённом месте документа, нужная для быстрого перехода к этому месту.

Создание закладки:

- Поставить курсор в нужное место
- Открыть Вставка и потом Закладка
- Ввести имя
- Нажать Добавить
- После этого можно открыть список закладок и перейти к нужной

#### Гиперссылки

Гиперссылка — ссылка, по которой можно перейти в другое место. Гиперссылка может вести:

- на сайт
- на файл
- на электронную почту
- на другое место в документе

Создание гиперссылки:

- Выделить текст.
- Выбрать Вставка и потом ссылка
- Указать место перехода
- Подтвердить
#### Оформление текста

При оформлении документа можно менять:

- шрифт
- размер шрифта
- начертание
- выравнивание
- отступы
- интервалы между строками
- интервалы между абзацами

Для оформления заголовков и текста используются стили. Основные стили:

- Обычный — основной текст
- Заголовок 1 — основной раздел
- Заголовок 2 — подраздел
- Заголовок 3 — раздел внутри подраздела
#### Титульный лист

Титульный лист — самая первая страница документа. Создать его можно через вставка потом титульная страница. На титульном листе обычно указывают:

- учебное заведение или заведение работы
- название самой работы
- вид работы
- ФИО студента/сотрудника
- группу
- ФИО преподавателя/руководителя
- город
- год
#### Список литературы

Список литературы содержит источники, использованные при выполнении работы. В него могут входить:

- книги
- учебники
- статьи
- сайты
- электронные документы

Для источника указывают автора, название и другие данные в зависимости от его типа. Список литературы располагается в конце работы.
#### Страницы

Параметры страницы находятся в формат потом стиль страницы

Здесь можно изменить:

- формат бумаги
- ориентацию
- поля
- колонтитулы
- фон страницы

Ориентация страницы бывает:

- книжная
- альбомная
#### Разрыв страницы

Разрыв страницы переносит текст на новую страницу. Он используется, когда новый раздел должен начинаться с новой страницы.

Создание:

- Вставка и потом разрыв страницы
- Разрыв страницы лучше использовать вместо большого количества нажатий Enter.

#### Разделы документа

Раздел — часть документа со своими настройками страницы. Для разных разделов можно задать:

- другую ориентацию
- другие поля
- свои колонтитулы
- другую нумерацию
- другое количество колонок
#### Нумерация страниц

Нумерация страниц добавляет номера к страницам документа. Создание нумерации страниц:

- Вставка и потом Номер страницы

Номер можно расположить:

- сверху страницы
- снизу страницы
- на полях

При изменении количества страниц нумерация обновляется автоматически.
#### Колончатый текст

Колонки — способ расположения текста в несколько вертикальных частей. Создание колонок:

- Макет → Колонки

Можно выбрать:

- одну колонку
- две колонки
- три колонки
- другие параметры

Также можно изменить ширину колонок и расстояние между ними.

#### Внесение исправлений

При редактировании документа можно:

- добавлять текст
- удалять текст
- заменять слова
- копировать текст
- перемещать текст
- искать нужные слова
- заменять слова через поиск

Функция отслеживания изменений показывает, что было изменено в документе. Можно увидеть:

- добавленный текст
- удалённый текст
- изменения форматирования

Исправления можно принять или отклонить.

#### Примечания

Примечание — комментарий к определённому месту документа. Примечания используют, чтобы оставить замечание или пояснение.

#### Составные документы

Составной документ состоит из нескольких разных элементов. В него могут входить:

- текст
- таблицы
- рисунки
- диаграммы
- ссылки
- другие объекты

Разные части документа можно объединять в одном файле.

#### Слияние документов

Слияние документов нужно для создания нескольких документов на основе одного шаблона. Например, так делают несколько писем с разными именами получателей. При слиянии используются:

- основной документ — общий текст
- источник данных — имена, адреса и другие данные
#### Колонтитулы

Колонтитул — область в верхней или нижней части страницы. В колонтитуле можно разместить:

- номер страницы
- название документа
- название раздела
- дату
- имя автора

Вставка - Колонтитулы - Верхний колонтитул  
Вставка - Колонтитулы - Нижний колонтитул

Колонтитул может отображаться на нескольких страницах.

#### Сноски

Сноска — дополнительная информация, связанная с текстом. Сноска обычно обозначается номером в тексте, а её содержание находится внизу страницы. Создание сноски:

- Ссылки и потом вставить сноску

#### Оглавление

Оглавление — список разделов документа с номерами страниц. 

Вставка - Оглавление и указатели - Оглавление, указатель или библиография

Для автоматического оглавления нужно использовать стили:

- Заголовок 1
- Заголовок 2
- Заголовок 3.
