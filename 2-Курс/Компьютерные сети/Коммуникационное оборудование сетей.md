## 1. Сетевое оборудование: понятие и классификация

**Сетевое оборудование** — широкий спектр устройств, которые служат для создания сетей передачи данных.

Сетевое оборудование делится на **две категории**:

1. **Активное** сетевое оборудование
2. **Пассивное** сетевое оборудование

![Сетевое оборудование: маршрутизаторы, витая пара и коннектор RJ-45](02-setevoe-oborudovanie.jpg)

---

## 2. Активное сетевое оборудование

**Активное сетевое оборудование** — любое устройство, проводящее цифровую обработку передаваемого сигнала.

К активному сетевому оборудованию относят:

- **Коммутаторы**
- **Маршрутизаторы**
- **Сетевые адаптеры**
- **Принт-серверы**
- **Модемы**

![Примеры активного сетевого оборудования (устройства D-Link)](03-aktivnoe-oborudovanie.jpg)

---

## 3. Коммутатор

**Коммутатор (свитч, switch)** — сетевое устройство, соединяющее узлы компьютерной сети в пределах **одного сегмента**.

Ключевое отличие от концентратора (хаба): коммутатор передаёт данные **только непосредственно получателю**, а не рассылает их на все доступные сетевые интерфейсы.

**Результат:** повышаются производительность и безопасность работы сети.

![Коммутатор с 16 портами RJ-45](04-kommutator.png)

---

## 4. Маршрутизатор

**Маршрутизатор (роутер, router)** — сетевое устройство, пересылающее пакеты сетевого уровня из одной подсети в другую по определённым правилам.

Основные функции и особенности:

- определяет путь (маршрут) передачи данных с помощью **таблицы маршрутизации**;
- позволяет делить сеть на **подсети**, увеличивая её производительность;
- применяется для **объединения разнотипных сетей**, иногда несовместимых по архитектуре и протоколам.

![Маршрутизатор Cisco 881 (вид сверху и задняя панель с портами)](05-marshrutizator.jpg)

---

## 5. Сетевой адаптер

**Сетевой адаптер (сетевая карта, сетевая плата)** — устройство, через которое компьютер **физически подключается** к сети.

Основные сведения:

- сетевой адаптер вместе со своим **драйвером** реализует работу на **физическом и канальном уровнях** модели OSI;
- адаптеры бывают **внутренние и внешние**;
- выпускаются версии **для коаксиального кабеля и для витой пары**.

![Внутренний сетевой адаптер PCI с разъёмом RJ-45](06-setevoy-adapter.jpg)

## 6. Принт-сервер

**Принт-сервер** — компьютер или специализированное устройство, позволяющее пользователям компьютерной сети получить доступ к принтеру, оснащённому интерфейсом **LPT или USB**.

**Задача принт-сервера** — превратить обычный принтер в сетевой.

«Продвинутые» принт-серверы обладают повышенной функциональностью:

- предоставляют дополнительную память для печати больших документов;
- разграничивают права доступа к принтеру.

![Принт-сервер (внешнее устройство с USB-интерфейсом)](07-print-server.jpg)

## 7. Модем

**Модем (модулятор-демодулятор)** — устройство, которое используется в телекоммуникационных системах.

**Виды модемов:**

| Вид | Где используется |
|---|---|
| **Аналоговые** | самая распространённая разновидность; работают на коммутируемых телефонных линиях |
| **xDSL** | создание высокоскоростных выделенных телефонных линий; телефонную линию можно использовать одновременно |
| **Кабельные** | передача данных по выделенному (телевизионному) кабелю |
| **Радио и спутниковые** | для передачи данных используют радиоканалы |

![ADSL-модем ZyXEL Prestige 600 series](08-modem.jpg)

## 8. Технология xDSL

**xDSL** — семейство технологий, которое на основе абонентской телефонной линии строит высокоскоростной канал передачи данных.

- Аббревиатура **DSL (Digital Subscriber Line)** — «цифровая абонентская линия».
- Вместо «x» в названии каждого стандарта семейства используется определённая буква: **ADSL, VDSL, HDSL**.
- xDSL использует **частотное разделение канала**, поэтому передача цифровых данных по телефонной линии **не мешает** работе обычной телефонной связи.

![Схема подключения абонента к сети по технологии xDSL](09-xdsl-shema.png)

## 9. Радиосвязь и Wi-Fi

- При помощи радиосвязи можно организовать подключение пользователей к сети там, где **затруднено кабельное подключение**.
- Представителем современных сетевых технологий, использующих радиоканал, является **Wi-Fi**.

## 10. Беспроводные среды передачи данных

Беспроводная среда передачи данных характеризуется **отсутствием необходимости в применении каких-либо кабелей**.

В компьютерных сетях используются две основные разновидности беспроводных сред передачи:

1. **Инфракрасная связь**
2. **Радиосвязь**

## 11. Инфракрасная связь

**Инфракрасная связь** — используется для передачи данных между различными цифровыми устройствами (мобильные телефоны, ноутбуки, цифровые фотоаппараты, компьютерная техника).

- **Инфракрасный порт (IrDA)** содержит в себе **передатчик** (специальный светодиод) и **приёмник** (фотодиод), которые работают в инфракрасном диапазоне.
- Инфракрасное излучение **не способно проникать сквозь преграды**, поэтому устройства необходимо располагать в условиях **прямой видимости** относительно друг друга.

![Устройство, использующее оптическое излучение (со слайда об инфракрасной связи)](12-ir-ustroystvo.jpg)

## 12. Ethernet

**Ethernet** — распространённая технология локальных компьютерных сетей.

- Стандарт Ethernet определяет взаимодействие узлов на **физическом и канальном уровнях** модели OSI.
- В настоящее время разрабатывается стандарт Ethernet, поддерживающий скорость передачи данных **до 10 Гбит/с**.

## Краткая шпаргалка

| Устройство | Суть |
|---|---|
| Коммутатор | Соединяет узлы **в одном сегменте**; данные идут только получателю |
| Маршрутизатор | Пересылает пакеты **между подсетями** по таблице маршрутизации |
| Сетевой адаптер | Физическое подключение ПК к сети; физический + канальный уровни OSI |
| Принт-сервер | Делает обычный принтер (LPT/USB) сетевым |
| Модем | Аналоговые, xDSL, кабельные, радио/спутниковые |
| Wi-Fi | Радиоканал там, где невозможна прокладка кабелей |
| IrDA | ИК-связь «в прямой видимости»: светодиод + фотодиод |
| Ethernet | Стандарт локальных сетей; физический и канальный уровни OSI |
