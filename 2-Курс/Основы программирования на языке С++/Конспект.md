## 1. Блок-схема

> [!info] Определение
> **Блок-схема** - графическое описание алгоритма: шаги изображаются геометрическими фигурами (блоками), а порядок их выполнения показывается стрелками (линиями потока).

### Основные элементы

| Фигура | Название | Что обозначает |
| --- | --- | --- |
| Овал (скруглённый прямоугольник) | Терминатор | Начало и конец алгоритма |
| Прямоугольник | Процесс | Вычисления, присваивание значений |
| Параллелограмм | Данные | Ввод и вывод данных |
| Ромб | Решение | Проверка условия, выходы «Да» / «Нет» |
| Шестиугольник | Подготовка | Заголовок цикла со счётчиком (`for`) |
| Прямоугольник с двойными боковыми линиями | Предопределённый процесс | Вызов функции / подпрограммы |
| Круг | Соединитель | Разрыв линии, переход на другое место схемы |
| Стрелка | Линия потока | Порядок выполнения блоков |

## 2. Типы данных

> [!info] Определение
> **Тип данных** определяет, какие значения может хранить переменная, сколько памяти она занимает и какие операции над ней допустимы.

| Тип | Что хранит | Размер* | Диапазон / точность* |
| --- | --- | --- | --- |
| `bool` | логическое значение `true` / `false` | 1 байт | 0 или 1 |
| `char` | один символ | 1 байт | −128 … 127 |
| `short` | целое число | 2 байта | −32 768 … 32 767 |
| `int` | целое число | 4 байта | −2 147 483 648 … 2 147 483 647 |
| `long long` | большое целое число | 8 байт | примерно ±9,2·10¹⁸ |
| `unsigned int` | целое число без знака | 4 байта | 0 … 4 294 967 295 |
| `float` | вещественное число | 4 байта | ~7 значащих цифр |
| `double` | вещественное число | 8 байт | ~15–16 значащих цифр |
| `void` | отсутствие типа | - | - |

\* Размеры зависят от компилятора и платформы; указаны типичные значения.

## 3. Условия и ветвление

> [!info] Определение
> **Условие** - выражение, которое принимает значение **истина** (`true`) или **ложь** (`false`). По результату проверки условия программа выбирает, какие действия выполнять.

Операторы сравнения: `==` (равно), `!=` (не равно), `<`, `>`, `<=`, `>=`.

### Полное ветвление

```cpp
if (условие) {
    // выполняется, если условие истинно
} else {
    // выполняется, если условие ложно
}
```

### Неполная конструкция ветвления

Ветка `else` отсутствует: если условие ложно, программа просто идёт дальше.

```cpp
if (x < 0) {
    x = -x;
}
```

### Условие else if

Позволяет проверить несколько условий по очереди. Выполняется блок первого истинного условия, остальные пропускаются.

```cpp
if (score >= 90) {
    cout << "Отлично";
} else if (score >= 70) {
    cout << "Хорошо";
} else if (score >= 50) {
    cout << "Удовлетворительно";
} else {
    cout << "Неудовлетворительно";
}
```

### Логические операторы

- `&&` - **И**: истинно, если истинны оба условия;
- `||` - **ИЛИ**: истинно, если истинно хотя бы одно условие;
- `!` - **НЕ**: меняет значение на противоположное.

| A | B | A && B | A или B | !A |
| --- | --- | --- | --- | --- |
| true | true | true | true | false |
| true | false | false | true | false |
| false | true | false | true | true |
| false | false | false | false | true |

```cpp
if (age >= 18 && age <= 65) { ... }
if (ch == 'a' || ch == 'e') { ... }
if (!(x > 0)) { ... }
```

## 4. Циклы

> [!info] Определение
> **Цикл** - конструкция, которая многократно повторяет набор действий (**тело цикла**). Один проход по телу называется **итерацией**.

- **Цикл с предусловием** - условие проверяется **до** выполнения тела (`while`, `for`). Тело может не выполниться ни разу.
- **Цикл с постусловием** - условие проверяется **после** выполнения тела (`do while`). Тело выполнится минимум один раз.

### Цикл while

```cpp
while (условие) {
    // тело цикла
}
```

```cpp
int i = 1, sum = 0;
while (i <= 10) {
    sum += i;
    i++;
}
```

### Цикл do while

```cpp
do {
    // тело цикла
} while (условие);
```

```cpp
int n;
do {
    cin >> n;
} while (n <= 0);
```

### Цикл for

```cpp
for (инициализация; условие; шаг) {
    // тело цикла
}
```

```cpp
for (int i = 1; i <= 5; i++) {
    cout << i << " ";
}
```

## 5. Одномерный массив

> [!info] Определение
> **Одномерный массив** - набор элементов одного типа, расположенных в памяти подряд и имеющих общее имя. Доступ к элементу осуществляется по индексу. Нумерация начинается с нуля: первый элемент - `a[0]`, последний - `a[N - 1]`.

### Объявление и инициализация

```cpp
const int N = 5;
int a[N];                    // значения не определены
int b[5] = {1, 2, 3, 4, 5};
int c[5] = {1, 2};           // {1, 2, 0, 0, 0}
```

### Ввод

```cpp
for (int i = 0; i < N; i++) {
    cin >> a[i];
}
```

### Вывод

```cpp
for (int i = 0; i < N; i++) {
    cout << a[i] << " ";
}
```

### Замена элементов

```cpp
a[2] = 100;                  // замена одного элемента

for (int i = 0; i < N; i++) {
    if (a[i] < 0) {
        a[i] = 0;            // замена элементов по условию
    }
}
```

## 6. Двумерный массив

> [!info] Определение
> **Двумерный массив** - таблица (матрица), в которой элемент определяется двумя индексами: номером строки и номером столбца - `m[i][j]`.

### Объявление и инициализация

```cpp
const int ROWS = 3, COLS = 4;
int m[ROWS][COLS];

int a[2][3] = {
    {1, 2, 3},
    {4, 5, 6}
};
```

### Ввод

```cpp
for (int i = 0; i < ROWS; i++) {
    for (int j = 0; j < COLS; j++) {
        cin >> m[i][j];
    }
}
```

### Вывод

```cpp
for (int i = 0; i < ROWS; i++) {
    for (int j = 0; j < COLS; j++) {
        cout << m[i][j] << " ";
    }
    cout << endl;
}
```

## 7. Размер массива

> [!note]
> Для определения размера в C++ используется оператор `sizeof` (оператора `typeof` в стандартном C++ нет).

`sizeof` возвращает размер в байтах. Чтобы узнать количество элементов массива, размер всего массива делят на размер одного элемента:

```cpp
int a[10];
cout << sizeof(a);                  // 40 - размер массива в байтах
cout << sizeof(a[0]);               // 4  - размер одного элемента
int n = sizeof(a) / sizeof(a[0]);   // 10 - количество элементов
```
