#### Текстовый процессор. Интерфейс. Создание и сохранение документа

Текстовый процессор— это программа для создания, редактирования, форматирования и печати текстовых документов. С его помощью можно работать с текстом, таблицами, списками, изображениями и другими объектами.
###### Основные элементы экрана текстового процессора:

- строка заголовка — показывает название программы и документа;
- меню — содержит команды для работы с документом;
- панели инструментов — кнопки для быстрого выполнения команд;
- рабочая область — место для ввода и редактирования текста;
- линейка — используется для настройки отступов и положения текста;
- масштаб — изменяет размер отображения документа на экране.

Для создания нового документа используется команда Файл → Создать или сочетание Ctrl + N.

Для сохранения используется Файл → Сохранить или Ctrl + S.

#### Создание и форматирование документа

Редактирование — это изменение содержания документа: добавление, удаление, копирование, перемещение и исправление текста.
Форматирование — это изменение внешнего вида текста и его расположения на странице.
###### При форматировании можно изменить:

- шрифт, его размер, цвет и начертание;
- выравнивание текста;
- отступы и интервалы;
- расположение текста на странице;
- списки и таблицы.

##### Разметка страницы определяет внешний вид страницы документа. Можно настроить размер бумаги, ориентацию и поля.
###### Основные виды ориентации:

книжная — вертикальное расположение страницы;
альбомная — горизонтальное расположение страницы.

Шрифт определяет внешний вид текста. Можно изменить его название, размер, цвет и начертание. Основные варианты начертания:
- жирный
- курсив
- подчёркивание.

Абзац — часть текста от одного нажатия Enter до следующего. Для абзаца можно установить выравнивание:

- по левому краю;
- по центру;
- по правому краю;
- по ширине.

Также можно настроить отступы, межстрочный интервал и расстояние между абзацами. Линейка используется для быстрой настройки отступов, положения первой строки и табуляции. Таблица состоит из строк, столбцов и ячеек. В таблице можно добавлять и удалять строки и столбцы, изменять размер ячеек, объединять ячейки и менять оформление. К специальным возможностям текстового процессора относятся проверка орфографии, поиск и замена текста, изменение масштаба и различные настройки отображения документа.

#### Выделение и операции с текстом

Для работы с определённой частью текста её необходимо выделить. Выделить текст можно с помощью мыши или клавиатуры. Для выделения всего документа используется Ctrl + A. С выделенным текстом можно выполнять следующие операции:

- копировать — Ctrl + C;
- вырезать — Ctrl + X;
- вставить — Ctrl + V;
- удалить — Delete или Backspace;
- изменить шрифт, размер и цвет;
- изменить начертание и выравнивание.

Контекстное меню открывается нажатием правой кнопки мыши. Оно содержит команды, которые можно использовать для выбранного объекта или текста. Например, копирование, вставку, удаление и изменение форматирования. Масштабирование изменяет размер отображения документа на экране. Например, при 50% страница становится меньше, а при 150% — больше. Масштаб не изменяет настоящий размер текста в документе. Предварительный просмотр позволяет увидеть, как документ будет выглядеть перед печатью. С его помощью можно проверить расположение текста, таблиц, изображений, полей и количество страниц.

#### Маркированные, нумерованные и автоматические списки

Список используется для расположения информации по отдельным пунктам. 

Маркированный список применяется, когда порядок пунктов не имеет значения и использует специальные символы перед пунктами:

- первый пункт
- второй пункт
- третий пункт

![[Pasted image 20260903134849.png]]

Нумерованный список использует числа или буквы:

1. Первый пункт.
2. Второй пункт.
3. Третий пункт.

Он используется, когда пункты имеют определённый порядок.

![[Pasted image 20260903134924.png]]
Автоматические списки создаются программой самостоятельно. Например, если начать строку с 1. и ввести текст, после нажатия Enter программа может автоматически создать следующий пункт с номером 2. Списки можно форматировать: изменять вид маркеров и нумерации, отступы, цвет и размер символов, расстояние между пунктами. Также можно создавать многоуровневые списки.

Пример:

1. Основной раздел  
    1.1. Первый пункт  
    1.2. Второй пункт
2. Следующий раздел

#### Стили и их создание

Стиль — это набор параметров форматирования, который можно применить к тексту одним действием. Cтиль может содержать:

- название и размер шрифта
- цвет;
- начертание
- выравнивание;
- отступы
- интервалы
![[Pasted image 20260903135044.png]]
В текстовых процессорах часто используются стили Заголовок 1, Заголовок 2, Обычный текст и другие. Стили позволяют быстро оформить большой документ и сделать одинаковыми заголовки, подзаголовки и основной текст. Для создания собственного стиля обычно нужно:

- Открыть раздел «Стили».
- Выбрать создание нового стиля.
- Указать название.
- Настроить шрифт, размер, цвет и выравнивание.
- Настроить отступы и интервалы.
- Сохранить стиль.
