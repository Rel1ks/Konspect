
Компьютерная сеть - это система объединяющая компьютеры и другие устройства (сервера, принтеры, маршрутизаторы) для обмена данными и ресурсами

Цель - удаленный доступ к разделяемым ресурсам (пользователи могут по сети получить данные с другого компьютера на расстояние)

![[Pasted image 20260923092806.png]]
##### Классификация компьютерных сетей

- По средне передачи данных (проводные и беспроводные)
- По скорости передачи данных (низкоскоростные, среднескоростные, высокоскоростные) 
  Низкоскоростные <100 Гигабит
  Среднескоростные 100-1000 Гигабит
  Высокоскоростные >1000 Гигабит
- По размеру охваченной территории (глобальные, региональные, локальные)
- По организации локальной сети (одноранговые и с выделенным сервером)

Трафик - объем передаваемых по сети данных. Различают входящий трафик данных, получаемых компьютером из сети, и исходящий трафик данных, отправляемых компьютером в сеть.  Измеряется в байтах

Скорость передачи данных - это фактическая скорость потока данных, прошедшего через сеть. Определяется как отношение объема переданных данных за промежуток времени на продолжительность этого промежутка. Базовая единица – бит/сек

##### Сетевые характеристики

Пропускная способность – максимально возможная скорость передачи данных по каналу связи. Зависит от качества и характеристики физической среды передачи данных и используемой технологии передачи данных

Топология сети – схема расположения и соединения сетевых устройств

От выбора топологии связей существенно зависят характеристики сети

Например, наличие между узлами нескольких путей повышает надежность сети и делает возможным распределение загрузки между отдельными каналами

#### Виды топологий

Полносвязная
![[Pasted image 20260923093742.png]]

+
- Высокая надёжность: если одна связь сломалась, есть другие
- Данные могут передаваться напрямую между устройствами
−
- Очень много кабелей и соединений
- Дорого создавать и обслуживать
- Сложно добавлять новые устройства

Ячеистая
![[Pasted image 20260923094003.png]]

+
- Высокая отказоустойчивость: есть несколько путей передачи данных
- Сеть может продолжать работать при отказе отдельных узлов или связей
- Устройства могут передавать данные друг через друга
−
- Дорогое оборудование и много соединений
- Сложно настраивать и обслуживать
- В большой сети управление становится трудным

Кольцевая
![[Pasted image 20260923094119.png]]

+
- Данные передаются по определённому порядку
- Меньше вероятность столкновения данных
- Относительно просто подключать новые устройства
−
- Обрыв связи может нарушить работу всей сети
- Сложнее найти неисправность
- Данные могут передаваться дольше, так как проходят через несколько устройств
- Если заразится один компьютер, то полетят все

Звездообразная («звезда»)
![[Pasted image 20260923094447.png]]

+
- Если один компьютер или кабель сломался, остальные продолжают работать
- Легко найти неисправность
- Просто подключать новые устройства
−
- При отказе центрального устройства перестаёт работать вся сеть
- Требуется много кабеля
- Количество устройств ограничено возможностями центрального устройства

Древовидная
![[Pasted image 20260923094658.png]]

+
- Удобно расширять сеть, добавляя новые ветви
- Легко разделить сеть на отдельные участки
- Подходит для больших сетей
−
- Отказ главного узла может отключить целую ветвь
- Сложнее настраивать и обслуживать, чем звезду
- Требуется много кабеля и оборудования

Общая шина
![[Pasted image 20260923094831.png|426]]

+
- Мало кабеля
- Простая и недорогая организация
- Легко подключить несколько устройств
−
- Обрыв основного кабеля может нарушить работу всей сети
- При большом количестве устройств сеть работает медленнее
- Сложнее найти место неисправности
- Возможны столкновения данных

Смешанная 
![[Pasted image 20260923100449.png]]

+
- Можно объединять преимущества разных топологий
- Гибко подходит под разные задачи
- Легко расширять отдельные части сети
−
- Сложнее проектировать и настраивать
- Дороже в создании и обслуживании
- Неисправность одного важного узла может повлиять на большую часть сети
